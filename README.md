# Teté Dog Toys (Bootstrap + filtros)
Abrir `index.html` directamente o subir a Netlify / GitHub Pages.

## Catálogo con filtros
- Filtra por **Talla** (S/M/L) y **Color** (rojo/azul/verde/mixto).
- Usa atributos `data-size` y `data-color` en `.catalog-item`.
- Botón **Limpiar** restablece el catálogo.
